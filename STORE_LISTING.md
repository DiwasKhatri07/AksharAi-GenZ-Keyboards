## Full description

Type Nepali, Nepinglish (Roman Nepali) and English with Akshar AI - GenZ Keyboards, an Android system keyboard made in Nepal. Switch between Devanagari Nepali, Nepinglish and English; use on-device transliteration, autocorrect, word suggestions, emoji ideas and gesture typing; and personalize the layout with curated themes, haptics, a number row and spacebar cursor controls.

An optional AI writing assistant offers 17 transformations, including Nepali/English translation, Gen-Z rewrites, captions, grammar fixes, smart replies, expand/shorten, and professional or respectful wording. Cloud AI requires a provider API key; local rule-based fallbacks are available. Review the privacy policy before enabling any keyboard or optional cloud-AI feature.
